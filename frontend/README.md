# City-Wide AI Multi-Camera ANPR, Vehicle Trajectory Tracking & Urban Traffic Analytics System - Frontend

This is the frontend portion of the City Traffic AI project, built with React, Vite, and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## Architecture Notes

* **`src/services/`**: API communication (REST, WebSocket)
* **`src/data/`**: Mock and demo data
* **`src/components/`**: Reusable UI components
* **`src/pages/`**: Complete screen views
